## 未覆盖 / 待办

1. **真实 Key 走查未执行**。本机 `%APPDATA%\ResearchPilot\config.yaml` 尚未配置任何真实
   Provider（只有默认 mock）。走查脚本对 Provider 无假设，配好之后直接重跑即可：

   ```bash
   cd backend
   uv run python ../scripts/slice_walkthrough.py --base http://127.0.0.1:8000 \
       --goal "你的真实研究目标"
   ```

   此时步骤 4 的 `llm.call` 帧会显示真实 provider/model/单价，`¥` 成本不再为 0。

2. **浏览器内的交互走查留到第 9 步**。本步只验证 HTTP 层链路；命令行的自由文本入口
   与「步骤实时渲染」是同一条链路的界面侧，第 9 步把前端接到 SSE 之后一次性在浏览器里
   走查（避免同一件事验两遍）。

3. **mock 的 `delay_ms` 不是新配置项之外的行为变更**：默认 0，原有测试与首启体验不变。

## 一处实现说明（容易踩）

自由文本入口的顺序是**先 PATCH `goal` 再触发 S1**。反过来会跑在旧目标上 ——
S1 的提示词构造时读取的就是 `project.goal`，所以这两步的顺序是有语义的，
不是一个可以随便调的调用序列。
